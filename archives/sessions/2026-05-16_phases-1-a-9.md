## Frictions rencontrées

- **ConceptGraph** : 3 itérations de fix nécessaires. Les deux
  premières (redraw post-clic, drag tolérant) traitaient des symptômes
  périphériques. Le vrai bug (scaling client→canvas) n'a été identifié
  qu'à la Phase 5 après remarque renouvelée de @ced. Leçon : creuser
  plus profond dès la première friction observée.

- **YAML frontmatter @-tags** : "@ced" non quoté = erreur YAML (arobase
  réservé). Bug détecté au build après sed bulldozer. Fix immédiat
  (quoting systématique).

- **Wraps ConceptLink Unicode** : la regex `\b` standard ne match pas
  les boundaries autour des caractères accentués (`leukê`, `troisième
  chose`). Script Python en remplacement de perl, avec lookarounds
  Unicode-aware `(?<![\w])` / `(?![\w])` et flag re.UNICODE.

- **Pluriel non capté** : "membrane" wrap échoué dans les-goorg.md où
  le texte dit "membranes". Adapté manuellement. Convention possible
  pour futurs : accepter `(?:s|es)?` à la fin.

- **Build sub-agent perl quoting** : les apostrophes typographiques
  vs ASCII (`'` vs `'`) ont posé problème pour matcher "fusion dans
  l'espoir". Non bloquant — la mention contextuelle ("La fusion est
  dans l'espoir") n'utilise pas la forme exacte du slug, donc skip OK.

- **Lighthouse sandbox** : Chrome headless indisponible + PSI API
  quota épuisé. Reporté en audit manuel sur pagespeed.web.dev.
